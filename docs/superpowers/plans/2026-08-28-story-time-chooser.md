# Story time chooser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the learner choose what a story is about before it starts, and be asked several level-appropriate comprehension questions as they read it.

**Architecture:** The topic is a `role: "topic"` message carrying the story's declared cast in its existing `needs` column, so it syncs with no schema change and flows into every segment's lexicon through one carry-forward function. Questions become a third prompt phase alongside telling, distinguished from segments by one new synced column `messages.kind`, and gated per level by a question ladder checked against the wordlists.

**Tech Stack:** No build step, no bundler, no dependencies, anywhere — including tests. Plain ES5-compatible browser JS in `index.html` and the extracted modules; plain node for tests with a `check(ok, label, detail)` counter.

**Spec:** `docs/superpowers/specs/2026-08-28-story-time-chooser-design.md`

## Global Constraints

- **No new dependencies, no `package.json`, no build step.** Not in the app, not in the tests.
- **Every extracted module ends with the same wrapper:** `if (typeof module !== "undefined" && module.exports) module.exports = api; else root.HSKPrompt = api;`
- **`VERSION` in `index.html` and `CACHE` in `sw.js` must move together** on every user-visible change. Current: `v68 — 2026-08-28` / `hsk-chat-v68`. Task 14 does the bump; do not bump in earlier tasks.
- **Any file the page loads must appear in `sw.js`'s `SHELL`.** This plan adds no new loaded file, so `SHELL` is unchanged.
- **Never hand-edit `data/hsk<N>.json`.** They are generated by `tools/convert.py`.
- **Schema changes go in `db/schema.sql` as `add column if not exists`**, and optional columns are probed once per session so an un-migrated database degrades instead of failing.
- **`PREFS_KEYS` in `sync.js` must never name `key` or `history`.** `test/sync.test.js` asserts this.
- **Prompt edits need a counted A/B against a real model before shipping** (CLAUDE.md). Tasks 4, 9 and 13 touch prompts; Task 13 is the measurement and must run before release.
- **Run the whole suite with `sh test/run.sh`.** One suite with `node test/<name>.test.js`. `test/browser.test.js` exits 0 without firefox and geckodriver, so a green run on a bare machine does not mean it passed.
- **Work on a branch; do not commit to `main`.** Current branch: `claude/activity-framework`.

- [ ] **Step 3: Add `needsSoFar()`**

In `index.html`, immediately after `castNames()`:

```js
/* Every [[NEED:]] word this conversation has already announced, up to and
 * including `upTo` (null means the whole conversation).
 *
 * A need used to be legal only in the reply that requested it, so a name the
 * story keeps using was a fresh violation in every later segment and spent
 * repair attempts on a word the app had already glossed. Scoped rather than
 * global: a word first needed in segment 2 must still be flagged in segment 1,
 * or rendering would once again disagree with what validation allowed. */
function needsSoFar(upTo) {
  const out = [];
  for (const t of S.history) {
    (t.needs || []).forEach(n => {
      if (!out.some(e => e.w === n.w)) out.push({ w: n.w, p: n.p, d: n.d });
    });
    if (upTo && t === upTo) break;
  }
  return out;
}
```

```js
/* How many segments this story has told.
 *
 * Counted from `kind` rather than derived from turn order. The old derivation
 * -- assistant turns before the first learner turn -- worked only while the
 * single question came last; questions now interleave, so the learner answers
 * mid-story and the count stopped at the first answer.
 *
 * A conversation written before `kind` existed has none on any message, so it
 * falls back to the old rule wholesale rather than per message: a mix would
 * count a legacy question as a segment. */
function storyTold() {
  if (S.history.some(t => t.kind)) {
    return S.history.filter(t => t.kind === "segment").length;
  }
  let n = 0;
  for (const t of S.history) {
    if (t.role === "user") break;
    if (t.role === "assistant") n++;
  }
  return n;
}
```

```js
// Four of the level's pool, shuffled, so the chooser is not identical every
// visit. Fisher-Yates over a copy -- sort(() => Math.random() - 0.5) is biased.
function sampleOf(list, n) {
  const a = list.slice();
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    const t = a[i]; a[i] = a[j]; a[j] = t;
```

```js
 * hand a beginner eight new words before segment 1; a higher level can carry a
 * fuller cast. Per D8 the table is complete rather than partial. */
const STORY_CAST_MAX = { 1: 3, 2: 3, 3: 4, 4: 4, 5: 5, 6: 5, 7: 6 };

/* Ask the story model who is in this story, before it writes any of it.
 *
 * The story model rather than the cheaper teaching one, and not for quality:
 * the cast it declares is the cast it will reach for when writing. A cast
 * declared by a different model is a guess about what a third party would name
 * its characters, and where the two disagree the story is back to using names
 * nobody announced. At ~$0.0023 the choice costs nothing to make.
 *
 * Best-effort: a failure returns no cast and the story is told anyway, with
 * [[NEED:]] catching names as they arrive, exactly as it does today. */
async function declareCast(topic) {
  if (!topic) return [];
  try {
    const raw = await callModel(
      [{ role: "user", content: HSKPrompt.castPrompt(topic, levelLabel(), castMaxFor(S.level)) }],
      200, storyModel());
    return extractNeeds(raw).needs
      .map(n => ({ w: n.w, p: n.p, d: n.d }))
      .slice(0, castMaxFor(S.level));
  } catch (e) {
    console.warn("cast declaration failed, carrying on without one", e);
    return [];
  }
}

 * "Make something up" passes "" and skips the call entirely, so the default
 * path costs exactly what story time cost before the chooser existed. */
async function startStoryWith(topic) {
  if (S.busy) return;

  finally { bubble.remove(); S.busy = false; renderBusy(); }
```

```js
 * short call, about $0.0002 -- and skipped outright where the learner has typed
 * their own title, which is what `renamed` has always meant. */
async function titleStory() {
  const c = currentChat();
  if (!c || c.renamed) return;
  const story = S.history.filter(t => t.kind === "segment" || t.role === "assistant")
    .map(t => t.text).join("\n");
  if (!story) return;

      [{ role: "user", content: HSKPrompt.titlePrompt(story) }], 40, teachingModel());
    const title = HSK.stripScaffold(raw).split("\n")[0].trim();
    if (title) { c.title = title; saveChats(); queueSync("conversations"); renderChats(); }
  } catch (e) {
    console.warn("could not title the story", e);   // the derived title stands
  }
}
```
